📊 Flowchart Terpadu Sistem Catering Mimi Saripah

100% Sesuai Antarmuka Web, Logika Routing Role di Session, & Relasi Tabel SQL (db_catering)

Terminal: Mulai / Selesai
Input/Output: Form / Layar
Process: Logika / Token / Hash
Decision: Validasi / Cek Role
Database: Tabung [(Tabel)]
Connector: Penghubung ((A-E))
flowchart TD
    StartApp(["Mulai Akses Web Catering Mimi Saripah"]) --> ViewHomePage[/Tampilkan Beranda: Hero Banner, Keunggulan, Menu Populer, Form Kesan & Pesan/]
    ViewHomePage --> NavPublik{"Pengunjung Ingin Mengakses Menu Lain?"}
    
    NavPublik -- "Lihat Profil" --> ViewAbout[/Tampilkan Halaman Tentang Kami: Sejarah Dapur Tenajar Lor & Kontak/]
    NavPublik -- "Jelajah Menu" --> ViewKatalogPublik[/Tampilkan Katalog Menu Publik & Filter Kategori/]
    ViewKatalogPublik --> ModalDetailPublik[/Modal Detail Paket Menu: Foto, Harga, Porsi & Deskripsi/]
    NavPublik -- "Pesan / Masuk" --> CheckAkses{"Pengunjung Ingin Memesan / Masuk Akun?"}
    ViewAbout --> CheckAkses
    ModalDetailPublik --> CheckAkses
    
    CheckAkses --> CheckPunyaAkun{"Sudah Memiliki Akun Terdaftar?"}
    CheckPunyaAkun -- "Belum (Akun Baru)" --> FormRegister[/Form Registrasi: Input Nama, Username, Email, No. Telp, Alamat, Password/]
    FormRegister --> ValRegister{"Validasi Registrasi: Data Lengkap & Username/Email Unik?"}
    ValRegister -- "Tidak Valid" --> ErrRegister[/Tampilkan Pesan Error: Username / Email Sudah Terdaftar/]
    ErrRegister --> FormRegister
    ValRegister -- "Valid" --> HashPass[Hash Password Pengguna via IPasswordHasher]
    HashPass --> SaveAkun[(Database: Simpan Akun Baru ke Tabel 'pengguna' - Peran_id = 2)]
    SaveAkun --> Conn_Login((A))
    
    CheckPunyaAkun -- "Sudah" --> Conn_Login
    Conn_Login --> FormLogin[/Form Login: Input Username & Password/]
    
    FormLogin --> CheckLupaPass{"Pengguna Lupa Kata Sandi?"}
    CheckLupaPass -- "Ya, Lupa Password" --> FormForgot[/Form Lupa Password: Input Email Terdaftar/]
    FormForgot --> KirimOTP[Generate 6-Digit OTP & Kirim via Email SMTP / Cache 15 Menit]
    KirimOTP --> FormReset[/Form Reset Password: Input Kode OTP & Password Baru/]
    FormReset --> ValOTP{"Validasi Kode OTP Cocok & Belum Kadaluarsa?"}
    ValOTP -- "Tidak Valid" --> FormReset
    ValOTP -- "Valid" --> SaveNewPass[(Database: Update PasswordHash Baru di Tabel 'pengguna')]
    SaveNewPass --> Conn_Login
    
    CheckLupaPass -- "Tidak, Masukkan Kredensial" --> ValLogin{"Kredensial Cocok & Akun Aktif (DeletedAt IS NULL)?"}
    ValLogin -- "Gagal" --> ErrLogin[/Tampilkan Pesan Error: Username atau Password Tidak Valid/]
    ErrLogin --> FormLogin
    ValLogin -- "Berhasil" --> GenSession[Generate JWT Token Cookie & Set Session: UserId, Username, Nama, Role]
    GenSession --> CheckRole{"Cek Peran Pengguna (Role di Session)?"}

    %% PERCABANGAN UTAMA ROLE
    CheckRole -- "Role == 'User' (Pelanggan)" --> Conn_User((B))
    CheckRole -- "Role == 'Karyawan'" --> Conn_Karyawan((C))
    CheckRole -- "Role == 'Pemilik Toko' (Owner)" --> Conn_Owner((D))

flowchart TD
    Conn_User((B)) --> CustDashboard[/Tampilkan Dashboard Pelanggan: Total Belanja, Pesanan Aktif, Menunggu Bayar/]

    CustTolakWilayah --> CustViewCart
    CustCekCoverage -- "Masuk Area Layanan" --> CustFormCheckout[/Form Checkout: Input Tanggal Acara, Jam Antar, Catatan Khusus/]
    
    CustFormCheckout --> CustCekHMin1{"Jadwal Pengiriman Minimal H+1 Sebelum Hari Acara?"}
    CustCekHMin1 -- "Hari Ini / Lampau" --> CustTolakHMin1[/Tampilkan Penolakan: Pemesanan Minimal H-1 Sebelum Acara/]
    CustTolakHMin1 --> CustFormCheckout
    CustCekHMin1 -- "Valid (>= H+1)" --> CustCekKuota{"Kapasitas Dapur Harian Masih Tersedia (Maks. 400 Porsi/Hari)?"}
    CustCekKuota -- "Kuota Penuh (> 400)" --> CustTolakKuota[/Tampilkan Penolakan: Kuota Dapur Tanggal Tersebut Telah Penuh/]
    CustTolakKuota --> CustFormCheckout
    CustCekKuota -- "Kuota Tersedia" --> CustCreateOrder[Generate Nomor Pesanan: ORD-YYYYMMDD-XXX]
    CustCreateOrder --> CustSaveOrder[(Database: Simpan Transaksi ke Tabel 'pesanan' & 'detail_pesanan' - Status 'Pending')]
    CustSaveOrder --> CustClearCart[Kosongkan Session Keranjang 'Cart']
    CustClearCart --> CustPilihBayar{"Pilih Metode Pembayaran"}
    
    CustPilihBayar -- "Transfer Bank Manual" --> CustBayarManual[Pilih Transfer Bank Manual: BCA, Mandiri, BNI, BRI]
    CustBayarManual --> CustUploadBukti[/Form Pembayaran: Unggah Berkas Bukti Transfer Bank/]
    CustUploadBukti --> CustSaveBukti[(Database: Simpan Transaksi ke Tabel 'pembayaran' - Status 'Menunggu Verifikasi')]
    CustSaveBukti --> CustConnTrack((E))
    CustPilihBayar -- "VA / QRIS" --> CustBayarInstan[Pilih Pembayaran Instan: Virtual Account / QRIS]
    CustBayarInstan --> CustConnTrack
    
    CustConnTrack --> CustTrackOrder[/Tampilkan Halaman 'Pesanan Saya' & Timeline Tracking Status Pesanan/]
    CustTrackOrder --> CustBatalCheck{"Pelanggan Ingin Membatalkan Pesanan?"}
    CustBatalCheck -- "Ya, Ajukan Batal" --> CustCekCutoff{"Batas Waktu Pembatalan Terpenuhi (Minimal H-2 Acara)?"}
    CustCekCutoff -- "Terlambat (< H-2)" --> CustTolakBatal[/Tampilkan Penolakan: Pembatalan Ditolak karena Melewati Batas H-2 Acara/]
    CustTolakBatal --> CustTrackOrder
    CustCekCutoff -- "Boleh (>= H-2)" --> CustFormRefund[/Form Modal Refund: Input Nama Bank, No. Rekening 8-20 Digit, Atas Nama/]
    CustFormRefund --> CustSaveRefund[(Database: Update Kolom Refund di Tabel 'pesanan' - Status 'Menunggu Refund')]
    CustSaveRefund --> CustConnTrack
    
    CustBatalCheck -- "Tidak, Menunggu Pesanan" --> CustTerimaPesanan[/Tampilkan Konfirmasi: Pesanan Tiba & Diterima Pelanggan di Lokasi/]
    CustTerimaPesanan --> CustFormTestimoni[/Form Ulasan: Input Rating Bintang 1-5 & Pesan Kesan Menu Acara/]
    CustFormTestimoni --> CustSaveTestimoni[(Database: Simpan Feedback ke Berkas JSON 'App_Data/kesan_pesan.json')]
    CustSaveTestimoni --> CustLogout[Klik Menu Logout: Hapus Cookie JWT & Bersihkan Session]
    CustLogout --> CustEnd(["Selesai Sesi Pelanggan"])
